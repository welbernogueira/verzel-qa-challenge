# Testes Manuais via Chrome DevTools — Verzel Store

## 1. Objetivo

Registrar as validações manuais realizadas diretamente pelo Chrome
DevTools, utilizando o Console e, quando necessário, a aba Network.

O objetivo é complementar os testes automatizados do desafio,
mantendo este documento restrito aos comportamentos relevantes
identificados durante a execução dos cenários propostos.

## 1. Ambiente
Aplicação:
https://verzel-store.qa-test-verzel-store.workers.dev/

Ferramentas utilizadas:
- Google Chrome
- Chrome DevTools
- Console
- Network
- Playwright para validação automatizada complementar
